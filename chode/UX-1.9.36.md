# Chode 1.9.36 — terminal branding

The terminal header has a compact colour logo derived from the website worker's three-node interference field and purple/pink HSL palette. It samples the field into contiguous block cells, so it is a low-resolution terminal rendering of the same pattern. Tests execute the actual worker logo and compare point gates, colours and alpha values.

The mark advances slowly at idle and faster while a worker is active. Waiting for a question returns it to idle speed. Animation updates only the reserved logo cells and restores the composer cursor; it does not make model or network calls. Small terminals retain the compact header. Monochrome output stays usable. Set CHODE_REDUCED_MOTION=1 before starting Chode to keep the mark static.

The website's white-letter reflection also has a small vertical deformation using the existing ripple clock. Its approved horizontal width, total height, faintness and horizon anchor remain intact. The removed hero slogan's responsive space is preserved.

YOLO is still queued and is not part of this release.
