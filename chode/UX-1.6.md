# Chode 1.6 — easier terminal workflow

The workspace has a centered start screen, a bordered composer, a quieter header, dark/light/system themes, and Ctrl+P command access. Tab cycles matching slash commands; Shift+Tab reverses. `/connect` explains provider setup without inviting credentials in prompts. `/export` saves the actual conversation as private Markdown in `.chode/exports`.

The gallery contains four assisted builds: a unit converter, CSV expense summary, architecture studio site and habit tracker. Live keyless requests produced drafts for the converter, expense tool and studio site; several requests timed out. The drafts failed independent quality checks and needed assisted repairs through Chode's local tools. The habit tracker was authored through those tools after its model request failed. These results are not evidence of fully autonomous build reliability.

Validation includes boundary cases for both programs, browser interactions for the sites, narrow/wide Unicode frame checks, command cycling, themes, exported content, and the full regression suite. OpenCode was used as an interaction reference, not as a measured parity claim.
