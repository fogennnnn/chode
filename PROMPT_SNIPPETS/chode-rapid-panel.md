# CHODE RAPID PANEL
## Introduction
The Chode Rapid Panel is a multi-agent prompt template designed to facilitate high-velocity hypothesis generation and edge-case testing.
## Panel Archetypes
The following panel archetypes are used in the Chaos Room:
1. **The Cross-Pollinator (Analogist)**: Maps structural invariants across disparate domains.
2. **The Gunner (Rapid Iteration & Edge Testing)**: High-velocity implementation with the smallest possible diff.
3. **The Synthesizer & Clarifier (Structural Architect)**: Integrates changes, resolves logic conflicts, and extracts core invariants.
4. **The Advocate of Truth (Devil's Advocate & Verification Enforcer)**: Checks for circular logic, hidden assumptions, and missing test proof.
## Usage
To use the Chode Rapid Panel, create a new instance of the panel and assign it to one of the available archetypes.
